# My-Coffee-Shop---Python-Project-
☕ Coffee Shop Sales Data Analysis
📌 Overview
This project analyzes sales data from a fictional coffee shop to understand customer behavior, popular items, payment trends, and overall business performance.
It is a beginner‑friendly data analysis project using Python, Pandas, and Matplotlib.

📁 Dataset
The dataset contains columns such as:
order_id
item
category
price
quantity
payment_method
order_time

🔧 Features
Load and explore dataset
Clean data (missing values, duplicates, incorrect entries)
Filter and sort rows
Group and aggregate data (sales, categories, payment methods)
Visualize trends using Matplotlib

📊 Insights
Coffee is the most sold item
Card payments are most common
Morning hours show peak sales
Pastries contribute strong revenue

🛠 Tools
Python
Pandas
Matplotlib
